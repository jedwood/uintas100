# Falcon guide hike index

Source: *Hiking Utah's High Uintas, 3rd ed. (Andrew Dash Gillman, Falcon, 2024)*. Generated by `scripts/build_hike_index.py` from the `guide_*` tables; **do not edit by hand**. Machine-readable twin: `data/hike_index.json` (same data plus full narratives).

How to query the JSON (examples):

```bash
# hikes 8–14 mi round trip that reach ≥3 lakes
jq '.hikes[] | select(.distance_mi_max>=8 and .distance_mi_max<=14 and .lake_count>=3) | {hike_number,name,distance_text,lake_count,primary_lakes}' data/hike_index.json
# hikes with grayling water, sorted by distance
jq '[.hikes[] | select(.species_current|index("Grayling"))] | sort_by(.distance_mi_max) | .[] | {hike_number,name,distance_text}' data/hike_index.json
# which hikes reach X-64
jq '.lakes[] | select(.letter_number=="X-64")' data/hike_index.json
```

Columns: **Dist** = round-trip miles as the book states them (a range means the book gives options; *one way* noted); **Elev** = destination elevation (ft); **Time** = hours; **Diff** = Easy / Moderate / Difficult / Extreme (note after the dash in the per-hike block); **Use** = book's usage; **Lakes** = DB lakes the hike's text names, minus pure name-drops like "Mirror Lake Scenic Byway" (fishable ones with no CAUGHT status counted under *Uncaught*); **Primary** = titled destination lake(s).
